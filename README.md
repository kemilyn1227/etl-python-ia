# ETL com Python e Inteligência Artificial

Projeto desenvolvido utilizando Python, Pandas e Google Gemini AI para demonstrar um processo ETL.

## Objetivo

Ler dados de uma planilha Excel, gerar mensagens personalizadas utilizando IA e exportar um novo arquivo com os resultados.

## Tecnologias utilizadas

* OpenPyXL
* Google Gemini API

## Fluxo ETL

1. Extract → leitura do Excel
2. Transform → geração de mensagens com IA
3. Load → exportação do resultado final

## Arquivos

* `Alunos.xlsx` → base original
* `resultado.xlsx` → arquivo transformado
* `etl_gemini_python.ipynb` → notebook principal
